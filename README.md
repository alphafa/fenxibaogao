# 三笙 · 商品开品分析工具 V9.3.0

V9.3.0 将采集、七角色分析、证据追溯和最终报告统一为一条输出链。报告面向不熟悉数据工具的商品、运营、设计、供应链和老板用户：先看结论，再按需展开专业分析与证据。

## 使用流程

1. 在淘宝或天猫商品页打开扩展。
2. 分析前选择评论样本：50、100、500、全部或自定义。
3. 开始采集；中途停止时保留当前进度，也可直接基于现有数据分析。
4. 等待七角色分析与总编审核完成。
5. 在报告中查看老板速览、下一款方向、页面转化、消费者洞察和完整角色分析。

## V9.3.0 输出结构

1. 老板速览：为什么能卖、值得继承、下一款优先。
2. 下一款方向：证据驱动优化、反馈驱动升级、探索性方向，并可立即生成开品任务。
3. 标题表达：当前表达、信息缺口和强化动作。
4. 主图分析：完整原图、信息任务、真实视觉信号和下一步动作。
5. 详情分析：代表图片、证明内容、页面承接和完整详情证据。
6. SKU分析：适配维度、组合顺序和供应链动作。
7. 消费者洞察：评论主题频次、体验差异、问题影响、产品动作和买家秀验证。
8. 七角色完整分析：核心判断、关键发现、执行动作、风险与验证。

## 统一渲染规则

- 所有图片使用 `object-fit: contain`，完整展示，不裁切。
- 图片不添加背景、模糊副本、边框、圆角、阴影、角标或序号。
- 空字符串、空数组、空对象、缺失图片和“暂无/未采集”占位项不进入最终页面。
- 某个卡片或章节无有效内容时，容器、标题和导航入口一起隐藏。
- 数值 `0` 与“用户主动停止”等真实采集状态保留。
- 证据优先显示来源类型和实际内容摘要，内部 evidenceId 仅作为次要追溯信息。
- JSON 动态报告和静态重建报告共用 `server/report.js`，避免两套样式漂移。

## 七角色

- 商品策略：商品定位、核心资产、差异与下一款策略假设。
- 电商转化：标题、主图、详情、信任证明与页面优化动作。
- 消费者洞察：稳定体验、差异、顾虑、问题与真实场景。
- 产品 / 供应链：材质、工艺、参数、SKU、风险与打样验证。
- 视觉设计：风格、颜色、花型、构图、拍摄和生图方向。
- 商业决策 / 老板：机会、优先级、保留项、升级项与执行顺序。
- 总编审核：事实、证据、对象、图片分类、冲突、重复和表达检查。

## 本地运行

双击 `start-tmall-ai.command`，或在 `server` 目录运行：

```bash
python3 server.py
```

默认服务地址为 `http://127.0.0.1:17962/`。扩展与后端版本必须一致。

完整规则见 `REPORT_OUTPUT_STANDARD_V9.3.0.md`、`PROMPT_ENGINEERING_V9.3.0.md` 和 `CHANGELOG_V9.3.0.md`。
