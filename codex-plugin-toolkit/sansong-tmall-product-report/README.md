# 三笙电商商品分析报告插件 v9.2.5

用于把淘宝/天猫当前商品采集结果转成跨类目商品分析、新品设计和 AI 视觉报告。

- `skills/tmall-product-analysis-report/SKILL.md`：跨类目分析与报告规范。
- `scripts/normalize_capture.mjs`：采集 JSON 标准化。
- `assets/capture-extension/`：通用商品页采集扩展参考。
- `assets/taobao_detail_fields_v8.3.6.xlsx`：保持原文件名的跨类目字段对照表。

报告明确展开标题、主图、详情、SKU、评论、商品价值结构、设计资产分级及 AI 生成规格；用户只负责采集并生成。
